# Music

The sound button plays these two songs in turn, round and round, if they are in this folder:

- `i-really-want-to-stay-at-your-house.mp3` (Rosa Walton)
- `still-love-you-slowed.mp3` (GLM-RST, slowed)

Use your own licensed copies; they are not included, and they should not be published with the site unless you hold
the rights to. Without them, the button plays the first song through Spotify's embedded player, and if Spotify cannot
load, HALCYON RADIO, an original score generated in the browser (js/music.js).
